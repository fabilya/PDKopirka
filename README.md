# PDKopirka

Калькулятор расчёта проектной документации с конвертацией Word → PDF.

## Сборка

```powershell
pwsh -File tools\build_release.ps1
```

Скрипт делает всё сразу: `pyinstaller` → полный установщик → облегчённый пакет
обновления, и печатает пути и SHA-256. По отдельности:

```powershell
pyinstaller PDKopirka.spec
iscc PDKopirka.iss                                   # полный (с LibreOffice)
iscc /DNoLO /DOutputSuffix=_Update PDKopirka.iss   # только программа
```

Облегчённый пакет нужен для автообновления: LibreOffice 7.3.7 статичен и его не
надо перекачивать при каждом релизе. Программа сама выбирает его, если
`url_lite` есть в `latest.json` и LibreOffice уже стоит рядом с программой.

Подпись артефактов (нужен личный код-сертификат — его нельзя сгенерировать):

```powershell
pwsh -File tools\sign.ps1 -Thumbprint "<отпечаток>"
```

## Встроенный конвертер (LibreOffice 7.3.7)

Word → PDF конвертируется через Microsoft Word (эталонная вёрстка). Если Word
на машине нет — используется встроенный портативный LibreOffice 7.3.7, который
лежит в папке `libreoffice` рядом с программой.

Почему именно 7.3.x: в этих документах штамп ГОСТ нарисован повёрнутыми
текстовыми блоками внутри группы фигур в колонтитуле. Word их рендерит
правильно, а LibreOffice начиная с 7.4 — нет (tdf#149395 / tdf#164868),
текст штампа рассыпается по буквам.

Перед сборкой установщика один раз подготовьте эту папку:

```powershell
pwsh -File tools\fetch_libreoffice.ps1
```

Скрипт скачает официальный MSI 7.3.7.2 (~330 МБ) и распакует его административной
установкой в `vendor\libreoffice` — без прав администратора и без установки в
систему. Папка `vendor\` в git не попадает.

Если папки нет, установщик соберётся без встроенного LibreOffice: программа
будет работать только там, где установлен Microsoft Word, и честно предупредит
об этом на странице «Готово».

## Установщик

```powershell
iscc PDKopirka.iss
```

Установщик сам определяет на машине Word и встроенный LibreOffice и показывает
на странице «Готово», какой конвертер будет использован.

## Отчёт о конвертации

Отчёт показывается **только в окне конвертации** — PDF-файла с отчётом нет,
чтобы его нельзя было случайно отправить на печать вместо документов.

После каждой партии программа:

- сверяет число страниц в DOCX и в получившемся PDF;
- проверяет, что шрифты документа есть в системе и внедрены в PDF;
- находит рассыпавшуюся рамку-штамп (текст без поворота, обрывки по 1–3 знака);
- сверяет номер листа в штампе с фактическим номером страницы;
- помечает файлы «✓ ок» / «⚠ проверить» / «✗ ошибка»;
- даёт скопировать отчёт текстом и открыть папку с готовыми PDF.

### Ограничение запасного движка (LibreOffice 7.3)

Поворот текста в штампе он отрисовывает правильно, но поля `PAGE` внутри
надписей штампа импортирует как обычный текст — номер листа в рамке остаётся
тем, что был записан в DOCX при последнем сохранении. Определяется автоматически
(проверка номеров листов в отчёте), но исправить это в LibreOffice нельзя:
только пересохранение через Word. Поэтому основной движок — Word.
